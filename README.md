# oficina-estado

Estado **en vivo** de la oficina virtual de Miguel: qué agente está trabajando, en qué fase va, cuánto suele tardar y
su última línea de resultado. Lo escriben los agentes (`oficina/herramientas/latido.sh`) y lo lee el hub cada minuto.

Es público a propósito: una página web no puede leer un repo privado sin exponer una llave. Aquí **no hay código,
llaves, datos de clientes ni contraseñas**: solo `estado/agentes.json`.
